# Contributing

Thanks for contributing to OpenDevKit.

## Before opening a pull request

- Explain the problem and the proposed change.
- Add or update tests when behavior changes.
- Do not commit API keys, tokens, cookies, or other secrets.
- Keep AI-generated changes reviewable and focused.
- Run `pytest -q` locally.

## Security-sensitive changes

Please avoid posting credentials or private repository contents in public issues. For suspected vulnerabilities, follow `SECURITY.md`.
